About ReBriefcase

ReBriefcase is a small piece of software made to replicate the functionality of the briefcases seen in Windows 7.

I chose to make ReBriefcase because I used Windows 7 Briefcases, and Microsoft decided to phase it out, and even removing it in later Windows 10 builds.

I have found other replicas online, but they tended to only bring back their look in Explorer, but left out the sync engine, and required messing with system files.

ReBriefcase does not touch system files, and can be installed like a normal program. It also has a sync engine, which is the whole point of briefcases.

Installing ReBriefcase

Installing ReBriefcase is the same as installing any other. All you have to do is click through the installer and ReBriefcase will be installed, no restarting or relogging needed!

After the installation is finished, there will be a new option in your context menu when you click on a folder. This is where you will use ReBriefcase.

ReBriefcase is compatible with any version of Windows that supports .NET v10.0, this includes Windows 10 and Windows 11, but ReBriefcase has only been tested on Windows 10.

Using ReBriefcase

To make a briefcase, first make a regular folder, and right click it. You should see a submenu labeld "ReBriefcase" if it installed correctly.

Click on the button labeled "Turn into briefcase". This injects the folder with metadata, and adds it to ReBriefcase's database to allow the folder to function like a briefcase.

The briefcase is still a folder after it's turned into a briefcase, so you can still use it as one. This is the closest way I could replicate the functionality with minimal extra steps and UI.

ReBriefcase also automatically renames "folder" to "briefcase" during the transormation process, to save you a few seconds of doing it yourself. It only does this with the word "folder", so it won't alter that name you gave the folder before hand.

Briefcases are not linked automatically, as this could lead to folder merging issues no one wants.

To link briefcases together, click the button labeled "Link to group". This will open a folder selection menu. Simply navigate to the briefcase you want to link and click "select folder". ReBriefcase will then link the two briefcases together in it's database.

ReBriefcase will make sure the folder you selected is compatible before attempting to link it to the briefcase, so you're safe from accidential confirmations.

ReBriefcase allows for as many briefcases to be linked together as you want or need, but keep in mind ReBriefcase has only been tested with at most 3 briefcases together.

Once at least 2 briefcases are linked together, ReBriefcase will allow you to sync them together. Simply click the button labeled "Sync with peers".

ReBriefcase's Sync Engine

ReBriefcase has 2 versions of it's sync engine, a "safe" method and an "unsafe" method

The unsafe method is what ReBriefcase will use when you first sync a peer group. This method is used only when ReBriefcase's database doesn't have a reference frame of the file system.

If you see this popup, it is best to sync the briefcases manually to prevent data loss, then click "yes". This method prioritizes larger file versions, regardless of when they were edited.

ReBriefcase also copies over time metadata, so all copies of a file share the same creation and edit dates.

The time it takes for the briefcases to sync depends on a few factors, such as the amount of files being synced, their size, and if there are conflicts.

For smaller syncs, the engine can get it done in a fraction of a second, and for larger jobs, the engine can take a few seconds to sort everything.

While ReBriefcase is generally fast, it is not as efficiant as it can be. ReBriefcase will be getting faster as updates roll out.

If you don't want to keep syncing 2 briefcases together, or if you want to archive a copy of a briefcase, you can simply click the button labeled "Unlink from group".

This will remove the connection to the database from the briefcase's metadata, but it keeps the rest. So you can relink again later.

ReBriefcase's Conflict Detection

ReBriefcase's conflict detection works differently compared to Windows' native briefcases.
