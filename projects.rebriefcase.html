About ReBriefcase

  • ReBriefcase is a small utility made to replicate the functionallity of the Windows briefcases found in Windows 7
  • I chose to make ReBriefcase because I did use briefcases from Windows 7, until Microsoft phased them out.
  • I found other replicas online, but they didn't include a sync engine, and requires replacing system files
  • ReBriefcase doesn't touch your system, while having a sync engine

    • Disclaimer

    ReBriefcase is still considered "Alpha" software, and can break and/or cause data loss. It is highly reccomended that you keep any valuable data stored in a safe location before using ReBriefcase.

    -KrForge
