Where KrForge Started

In 2016, I tried Scratch for the first time for school. I was taught how to make Flappy bird. Something about being able to tell the engine what to do clicked with me, and it got me interested in coding.

I would later learn Python, because I read online it was beginner friendly. I learned a lot about how programming actually works. I learned programming was tedious, but it was just as rewarding when it worked. I made a bunch of random little things with Python, and experimented with new concepts, such as image generation and editing, encryption, and file systems. Every project taught me something new, and I loved it.

However my interest in coding died off for a while, because life got in the way. School, friends, family, growing up.

Sometime in 2022, I discovered the Godot Game Engine. It was described as being a beginner friendly game engine, with a built-in language, similar to python. I was very interested in it, and was inspired to make my own game. This experience brought my coding interest back to life, and I had a fairly easy time learning the engine, since I was familliar with Python. The interest never died off since.

What KrForge Is

Recently, I've grown to hate the direction the internet has been going in, an endless march towards more data collection, AI being shoved into literally anything that could potentially warrent it, and less privacy.

I've chosen to write software that can't spy on you even if it wanted to. None of my software will ever touch the internet when on your computer. It's entirely local, as all software should be.
